# Corner Coffee ☕

**Corner Coffee** — a family-run café on the town square in **Trenton, Georgia**, serving locally roasted espresso (Goodman Coffee, Chattanooga), hearty breakfasts and lunch.

📍 **48 Court St, Trenton, GA 30752** · 📞 (706) 500-1133 · ✉️ cornercoffeetrenton@gmail.com

## The website

A warm, single-page café site with:

- Full-screen 16:9 hero
- Our Story section
- Full interactive **menu** (Breakfast, Lunch, Espresso & Brew, Blended & Smoothies, Tea & Extras)
- A no-crop photo **gallery** (masonry collage + lightbox)
- Google **reviews**
- Visit section with map, hours & directions

## Stack

Plain **HTML / CSS / vanilla JS** — zero dependencies, no build step. It's a fully static site.

- Fonts: [Fraunces](https://fonts.google.com/specimen/Fraunces) & [Manrope](https://fonts.google.com/specimen/Manrope) via Google Fonts

## Run locally

```bash
# from this folder
python3 -m http.server 8000
# open http://localhost:8000
```

…or just open `index.html` in a browser.

## Deploy

Works as-is on **Vercel / Netlify / GitHub Pages** (static site, no build command needed).
